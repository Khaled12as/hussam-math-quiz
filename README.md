# مسابقة رياضيات الصف الثاني عشر علمي

صفحة واحدة (HTML/CSS/JS) لاختبارات مراجعة الرياضيات — بدون أي مكتبات أو خادم.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```powershell
npx serve .
```

## المحتوى

- اختيارات من الكتاب كاملًا، اختبار سريع (20 سؤالًا)، أو فلترة حسب الوحدة والدرس
- أسئلة صح/خطأ واختيار من متعدد مع شرح لكل إجابة
- النتائج تُحسب فورًا مع نسبة مئوية
